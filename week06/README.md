# 6주차 Docker 실습 

## 1. 실습 목표 
- Dockerfile를 작성하여 Guestbook v1로 웹 브라우저 방명록 작성
- 빌드한 Docker 이미지를 컨테이너로 실행
- ghcr에 docker 이미지 업로드 

## 2. 내 이미지 주소
 ghcr.io/wrwer123/guestbook:v2

## 3. Dockerfile 설명
FROM: 기반 이미지 지정 
WORKDIR: 작업 디렉터리 설정 
COPY: 파일을 이미지에 복사 
RUN: 이미지 빌드 중 명령 실행
ENV 이름=값: 환경변수를 설정하여 기본값을 이미지에 저장
EXPOSE: 포트 번호를 문서화
CMD: 컨테니어 시작 시 실행할 명령 지정 

## 4. 빌드 캐시 
- Docker는 이전 빌드에서 생성한 결과를 캐시로 저장하고, 변경 사항이 없으면 재사용 한다.

- CACHED: 이전 빌드 결과를 재사용한 단계 
- 코드가 변경되면 해당 단계부터 다시 빌드될 수 있다.
- requirements.txt를 먼저 복사하고 라이브러리를 설치하면, 코드만 수정했을 때 라이브러리 설치 단계를 재사용할 수 있다.

 이를 통해 불필요한 작업을 줄이고 이미지 빌드 시간을 단축할 수 있다. 

## 5. 설정 방법 비교
- 코드에서 설정: 애플리케이션 코드에서 값을 직접 지정한다.
- ENV: 이미지에 기본 환경 변수를 설정한다.
- -e: 컨테이너 실행 시 환경변수를 전달하거나 기본값을 덮어쓴다.

- 설정 우선순위 
 코드 기본값 < Dockerfile ENV < docker run -e
