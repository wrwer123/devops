# GitHub Issue 실습

### 작업 내용
- Docker 실행 환경 및 nginx 실행 확인
- Issue를 기준으로 작업 진행
- 작업 브랜치를 원격 저장소에 Push
- Pull Request 생성

### 작업 흐름
Issue -> Branch -> PR -> Merge -> Issue Close

### 수업 내용
- Issue: 작업 내용과 진행 상황 관리
- Branch: 작업을 분리하여 진행하는 공간
- Pull Request: 변경 내용을 검토하고 병합을 요청
- Merge: 변경 내용을 대상 브랜치에 반영
- PR 본문에 Close #이슈번호를 작성하면 Merge 후 Issue가 자동으로 종료될 수 있다.
