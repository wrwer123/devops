3주차 Qwen 웹 프로그램 실습 

1. 실습 내용 
- Ollama 설치 및 실행 
- python3 버전, ollama 버전 확인
- 셸 스크립트 start.sh 작성 
- 셸 스크립트 실행 권한 설정 

2. 실행 결과 
- Ollama 서버 실행 여부를 확인
- 웹 프로그램을 실행한 후 http://localhost:8000에 접속
- 질문을 입력하고 답변이 표시되는지 확인 
- start.sh 실행에 필요한 권한을 설정

3. 수업 내용 
- 셸 스크립트는 여러 명령어를 파일에 작성하여 순서대로 실행하는 방법이다. 
- chmod u+x start.sh 명령어로 실행 권한을 설정한다. 
- ./start.sh 명령어로 셸 스크립트를 실행한다.
- 환경 변수를 이용해 프로그램의 설정값을 지정할수 있다.
